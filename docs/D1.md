## What differs from von

| | von | d1-omni |
|---|---|---|
| Backbone | ModernBERT-large, 28 layers | LFM2.5-Encoder: 10 short-conv + 6 GQA layers, bidirectional |
| Rows per question | 1, plus a null pass for default Noul | 1 |
| Head | MLP at `[MASK]` positions | question-type embedding, 2 pre-norm transformer layers, MLP |
| Calibration | input-conditioned temperature map | fixed temperature per type and option-count bucket (text only) |
| Answers | rounded; confidence = p1 - p2 | unrounded; confidence = max p |
| Media | none | image or audio prefix embeddings, shared trunk |
| Usage | approximate characters / 4 | positions read (prefix + tokens), 0 output |

Both use the same Decision Index question schema, so `SystemOneEngine`,
`QuestionEntry`, and the answer types are shared.

## Prompt (`D1Prompt`)

```
<bos> <|reserved_7|> state <|reserved_8|> instructions
      (<|reserved_9|> <|mask|> option <|reserved_10|>)×k <|reserved_11|>
```

- Caller text has every `<|name|>` rewritten to `<¦name¦>`, so a state cannot
  forge a delimiter or marker. `D1ModelProfile.markerText` is therefore `nil`.
- A text state passes through; ordered fields serialize like
  `json.dumps(state, ensure_ascii=False)`.
- The option block gets `max(96, min(24k + 32, maxLength / 2))` tokens, split
  evenly across options; the state is truncated on the right to fit.
- Options: Choice `key: description` (the key alone when the description is
  `nil` or empty); Score `level i: text`; Noul `[false, true]` with defaults
  "no, the statement does not hold" / "yes, the statement holds".
- Image requests use 896 text positions and plain `false: no` / `true: yes`
  Noul defaults. Audio requests use 15,360, write choices as
  `option_000: description`, and always use the plain Noul.
- Usage counts every position the trunk reads.

`D1Tokenizer` loads `tokenizer.json` with swift-transformers' BPE tokenizer,
mapping transformers 5's `TokenizersBackend` class to `PreTrainedTokenizerFast`.
Ids match Python on the fixture's Unicode, emoji, RTL, code, and long inputs.

## Trunk and head (`D1Trunk`, `D1DecisionHead`)

- Short conv layers: `out(c · conv3(b · u))` from a 3×d input projection, with
  a centred depthwise 3-tap kernel. Inputs are zeroed at padding first.
- Attention layers: GQA (16 query, 8 KV heads), per-head RMSNorm on Q and K,
  non-traditional RoPE with θ = 1e6 over absolute positions.
- SwiGLU feed-forward of width 4,608; RMSNorm everywhere; a final RMSNorm.
- A media prefix attends only to itself and the last prefix position never
  reads the first text position through the convolution, so the prefix is a
  function of the media alone. A request runs it through the trunk once and
  caches what text reads from it: each attention layer's keys and values
  (after RMSNorm and RoPE) and each conv layer's last `b · u`. Every question
  then runs only its text positions, from RoPE position P, against those
  states. The reference re-runs the prefix per question; logits agree with
  that path to 5e-5.
- The head adds a type embedding (choice 0, score 1, noul 2), runs two
  PyTorch `TransformerEncoderLayer`s (pre-norm, ReLU, 16 heads) over text
  positions, and scores markers with LayerNorm → Linear → GELU → Linear.

## Vision (`D1Vision`)

- `layout`: LFM2-VL smart resize (32-pixel factor, 64–256 projected patches per
  crop). Images over twice the budget are cut into up to ten 512-pixel tiles
  plus a thumbnail. The grid search follows CPython's set order, embedded as
  `D1Vision.tileGrids`.
- Crops are resized with ATen's uint8 antialiased bilinear kernel, reproduced
  bit for bit in `AntialiasedResize` (int16 weights, horizontal then vertical
  pass, uint8 intermediates). On arm64 torchvision takes this native path.
- SigLIP2 NaFlex: patch Linear plus a 16×16 position grid resized with the
  float antialiased kernel; 12 pre-norm layers (tanh GELU, LayerNorm ε = 1e-6).
  Each crop runs unpadded, equivalent to the reference's key-padding mask.
- 2×2 pixel unshuffle, then Linear → GELU → Linear into the trunk width: one
  prefix embedding per 32×32 pixels.

## Audio (`D1Audio`)

- Clip cut to 30 s, padded to 0.5 s. Preemphasis 0.97; centred 512-point STFT
  with hop 160 and a symmetric 400-sample Hann window; power spectrum; Slaney
  mel (128 bins, `MelFilterbank`); `log(x + 2^-24)`; per-feature normalization
  over the `n / 160` valid frames.
- 8× ConvSubsampling (3×3 stride-2 conv, then two depthwise-separable stride-2
  stages) with the time mask reapplied before every module.
- 17 FastConformer layers: half-step FFNs, Transformer-XL relative-position
  attention (`rel_shift` implemented as a gather at column `t-1-i+j`), a
  GLU/depthwise-conv module with folded BatchNorm, and an output LayerNorm. The
  conformer runs over valid frames only, equivalent to its masks for one clip.
- Adapter (LayerNorm → Linear → GELU → Linear) and a residual correction:
  one prefix embedding per 80 ms.

## Parity (GPU, `D1_DEVICE=gpu`)

| Check | Result |
|---|---|
| Tokenizer ids, prompt ids and markers, escaping | exact |
| Layouts, crop bytes, position grids | exact |
| Trunk probes (18 boundaries × 16 dims) | 1.1e-5 relative |
| Head logits (single and batched rows) | 5.8e-5 absolute |
| Image / audio row logits over cached prefix states | 1.0e-4 / 3e-5 absolute |
| SigLIP2 tower / image prefix | 3.6e-5 / ~1e-5 relative |
| Mel / conformer / audio prefix | 2e-6 / 3e-6 / 2e-6 |
| Text, image, and audio answers | within 2e-3 (text 1e-6 from golden logits) |

answers are compared with the reference's batched logits.
